# Size-Exchange Policy

Size exchange applies only to Apparel and Footwear, where fit rather than quality is the problem.

- A customer may exchange one line item for a different size once per order, within the same 14-day return window, and the replacement must be the same style and colour.
- The exchange is free: the new size is dispatched after the original item is picked up and passes quality check, and any price difference between sizes is neither charged nor refunded.
- If the requested size is out of stock, the request is converted into a refund automatically.
- Electronics, Home and Beauty items have no size exchange and must go through a normal return.
